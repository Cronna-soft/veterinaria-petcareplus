# PetCare+ Veterinaria - SPA Profesional

**PetCare+** es una aplicación web moderna enfocada en **la gestión de citas veterinarias** y **la presentación de servicios para el cuidado de mascotas**, diseñada para ofrecer una experiencia clara, rápida y confiable tanto para usuarios como para clínicas veterinarias.

Este proyecto simula un entorno real de negocio, integrando interacción dinámica, conexión a base de datos y experiencia de usuario optimizada. Permitiendo a los usuarios **explorar servicios**, conocer la clínica y agendar citas, integrando una arquitectura frontend moderna con conexión a backend mediante **Supabase**.

## 🌐 [Visitar el Sitio Web](https://veterinaria-petcareplus.vercel.app/) en Vercel

### Descripción
PetCare+ fue desarrollado como parte de un proceso de aprendizaje como un proyecto profesional de portafolio enfocado en la creación de sitios web completos y funcionales. A diferencia de una landing estática, este proyecto incorpora lógica real de interacción con el usuario, incluyendo el registro de citas en una base de datos. Con el objetivo de simular un sitio web funcional para una veterinaria real, aplicando buenas prácticas de desarrollo frontend moderno.

---

Se ha trabajado bajo un enfoque profesional de:

- Experiencia de usuario clara y fluida
- Interfaz responsive (mobile-first)
- Interacción dinámica con React
- Conexión a base de datos real para gestión de citas

### Características Destacadas

✅ Formulario de citas funcional conectado a base de datos mediante **Supabase**
✅ Validaciones en tiempo real para mejorar la experiencia del usuario
✅ Diseño responsive optimizado para múltiples dispositivos
✅ Sección de servicios dinámica cargada desde datos estructurados (/mock)
✅ Navegación clara y estructurada enfocada en conversión
✅ Arquitectura basada en componentes reutilizables
✅ Optimización para experiencia mobile-first

### Tecnologías Utilizadas

- **React.js** — Construcción de interfaces dinámicas
- [**Vite**](https://vite.dev/guide/) — Entorno de desarrollo rápido y optimizado
- [**React Router**](https://reactrouter.com/home) — Navegación entre páginas
- [**MUI X**](https://mui.com/x/react-date-pickers/) — Librería de componentes (DateCalendar y DigitalClock)
- **CSS3**/[**TailwindCSS**](https://tailwindcss.com/docs/installation/using-vite) — Estilización personalizada y responsive
- [**Supabase**](https://supabase.com/) — Backend como servicio (Base de datos)
